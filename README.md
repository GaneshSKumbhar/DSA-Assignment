## Description

This project contains implementations of various DSA topics, including string operations, matrix manipulations, linked lists, stacks, queues, trees, graph algorithms, sorting, and hashing. Each assignment is organized in its own folder (e.g., `Assignment 1/`) and includes:

- C++ source code (`.cpp`)
- Detailed documentation (`.md`)
- Compiled executable (`.exe` for Windows)
- Supporting images (diagrams or output screenshots)

The assignments are numbered from 1 to 60 and cover a wide range of topics to build a strong foundation in DSA.

## Prerequisites

- A C++ compiler (e.g., g++ from MinGW, Visual Studio, or any standard C++ compiler)
- Basic knowledge of C++ programming
- Windows OS (for running `.exe` files; source code can be compiled on other platforms)

## How to Run

1. Navigate to the desired assignment folder (e.g., `Assignment 1/`).
2. Compile the C++ source file using a compiler:
   ```
   g++ filename.cpp -o output.exe
   ```
   Replace `filename.cpp` with the actual `.cpp` file name (e.g., `1_1_StrinOperation.cpp`).
3. Run the executable:
   ```
   output.exe
   ```
4. Alternatively, run the pre-compiled `.exe` file directly if available.

For detailed instructions, refer to the `.md` file in each assignment folder.
